# dsh-exam-gen

**装完即用，不需要注册、不需要填任何 API Key。**
**模型调用走你自己 DSH 里已配置的模型，插件永不持有、永不索要 Key。**
**数据和题目只在本机，不上传、不回传。**

DSH 出题插件：初高中理科组卷、专项突破、教学讲义、知识图谱、教材同步，本地渲染可打印 PDF。

---

## 一、先说设计决策（因为它决定了你看到的每一个细节）

### 1. 参数表只有两个字段，其余在本地解析

工具说明是**每轮请求的常驻成本** —— 模型还没开始干活，你已经在为它付钱。所以参数表压到 `{ brief, quality }`：

```
你：初二数学一元一次方程 8 道选择题
插件：自己解析出 年级=初二 科目=数学 范围=一元一次方程 题数=8 题型=选择题
```

十几个参数变成一句话，工具说明从约 1580 token 降到约 500。解析不出来的字段一律走默认值，**绝不因为「没说清楚」卡住你**。

### 2. 排版不花 token

模型只输出结构化 JSON，分式、上标、选项对齐、密封线、页眉页脚全部由本地 pdfkit 画。
一次渲染 40 毫秒，**0 token**。

模型写 Markdown 给你的是 `1/2x − 3x = 15` —— 学生分不清是 (1/2)x 还是 1/(2x)。插件画的是真分式：

```
  2x-1        x+2
 ──────  −  ──────  = 1
    3          4
```

### 3. 风格是固定下来的，不靠模型临场发挥

`src/style-anchors.ts` 里硬编码了 15 道真实卷面题（初高中数学、物理、化学），每次出题按学科注入 2 条当范例，模型照着这个问法与信息密度写。

**题库以后怎么换，风格都不变。** 这是「固定真题风格」的落点。

### 4. 能被本地算出来的，绝不问模型

| 环节 | 谁做 | 花多少 token |
|---|---|---|
| 想参数 | 插件解析原话 | 0 |
| 排版 | pdfkit | 0 |
| 校验（答案是否在选项里、选项数量、题干长度） | 插件 | 0 |
| PDF | pdfkit | 0 |
| 出题 | 模型 | 有 |

题库命中时（`quality: 'turbo'`）连出题都是 0 token：30 毫秒从 3340 道题里拼一套出来。

### 5. 不写本地缓存目录

PDF 只在内存活 10 分钟（下完就散），题库是包内只读文件，加的自定义题写回题库文件本身。
**卸载即净，不留垃圾**，所以不需要 onUninstall 钩子。

## 二、安装

```bash
dsh plugin --profile <你的profile> add https://github.com/hj178250/dsh-exam-gen/releases/download/v1.0.0/dsh-exam-gen-1.0.0.tgz
```

（可选，想要参数卡片）再装一次卡片底座：

```bash
dsh plugin --profile <你的profile> add dsh-tool-cards
```

**装完检查一行**（tgz / 本地文件安装的通病）：打开 profile 的 package.json，确认 dsh.profile.bundles 里有 dsh-exam-gen（装了卡片底座就再加 dsh-tool-cards）。pnpm 直接 dd 一个 tgz 不会自动写这一行，缺了插件不加载。


装完在 DSH 里说一句就能用：

```
初二数学一元一次方程 8 道选择题
```

### 安装时可能遇到的三件事（都实测过）

**1. pnpm 报 `ERR_PNPM_IGNORED_BUILDS`**

pnpm 10+ 默认不执行依赖的 postinstall 脚本。我们的 postinstall 只做一件事：给 dsh-tool-cards 打一条路由补丁（不打的话参数卡片点提交会 405）。

包**已经装好了**，只是脚本没跑。二选一：

```bash
# 方案一：允许执行
pnpm approve-builds          # 然后在 profile 目录里重装一次
# 方案二：手动跑一次补丁（幂等）
node node_modules/dsh-exam-gen/scripts/patch-tool-cards.mjs
```

插件启动时会自己检查补丁状态，没打就在日志里告诉你怎么补。**出卷、PDF、题库管理页不受这件事影响。**

**2. 用本地 tgz 安装时，工具没出现在对话里**

`dsh plugin add <file>.tgz` 会把包写进 profile 的 `dependencies`，但**不会自动把包名加进 `dsh.profile.bundles`**（从 npm registry 装才会）。手动加一行：

```json
"dsh": { "profile": { "bundles": ["@deepseek-ai/dsh-base", "@deepseek-ai/dsh-web-app", "dsh-exam-gen"] } }
```

**3. 安装路径不要含中文**

`dsh plugin add` 会把路径写进 profile 的 `package.json`，中文路径在 pnpm 里会变成乱码（实测 `Downloads/新建文件夹` → `Downloads/鏂板缓鏂囦欢澶?`），包就装不进去。放英文目录再装。

## 三、五个功能

一句话触发，插件自己判断你要哪个：

| 说法里的关键词 | 走哪个功能 | 输出 |
|---|---|---|
| 卷子 / 试卷 / 题 | 智能组卷 | 高考卷式 PDF（注意事项、密封线、考生栏、答案页分开） |
| 专项 / 变式 / 突破 | 专项突破 | 专题练习册（难度递进 + 每题变式说明 + 方法总结） |
| 讲义 / 教案 / 备课 | 个性化教学讲义 | 家教讲义（知识点 → 例题精讲 → 变式练习 → 小结） |
| 图谱 / 知识树 / 梳理 | 知识图谱梳理 | 纯文本层级表（年级 → 章 → 节 + 每节点题量） |
| 同步 / 教材 / 课时 | 教材同步训练 | 同步练习页（基础/提高两区 + 「□会 □不太会」+ 知识点标注） |

### 出题档位

```jsonc
{ "brief": "初二数学一元一次方程 8 道选择题" }              // premium，默认
{ "brief": "初二数学一元一次方程 8 道选择题", "quality": "turbo" }  // 只用题库，0 token
```

- **premium**（默认）：模型按真题风格现出，质量优先，约 80~90 秒
- **turbo**：只从 3340 道题库里抽，30 毫秒、0 token，问法偏直白

## 四、题库

- **3340 道题 / 425 章 / 2.04 MB**，随包分发
- 覆盖：数学 2187（初中 1407 / 高中 784）、物理 721、化学 432
- 题型：选择 1698 / 填空 1624 / 解答 29；难度：基础 1563 / 中档 1470 / 拔高 318
- 每题都带答案与解析

### 题库管理页

```
http://127.0.0.1:<你的端口>/exam-bank
```

浏览器里翻页、搜索、按学科/难度/来源筛选、新增题目、导入 JSON、导出当前结果。
**零模型 token**。地址和 token 在插件启动日志里。

## 五、token 账（说实话）

| 项 | 成本 |
|---|---|
| 工具说明（常驻） | ~500 token，每轮都付 |
| 出题 prompt | 883 字符（约 450 token），每次生成付一次 |
| 模型输出（8 道题） | ~1200 token |
| 排版 / 校验 / PDF / 参数解析 | **0** |

**和直接对话比，插件在 token 上基本打平，优势在「直接对话做不到的事」**：

- 可打印的真卷（直接对话里的分式是斜杠，选项挤成一行）
- 答案本地校验（选项越界会被拦下重试）
- 参数不用每次复述
- 五种版式各不相同
- 题库直出时 0 token

如果只比 token 不比别的，直接对话更省。这一点不粉饰。

## 七、已知限制

1. **题型混排会退化**：题库里某章节的选择题不够时，要么少给几道（默认），要么混入其它题型（`turbo` 模式）。混入时模型可能自作主张改写题型。
2. **几何图形画不出来**：题干里写「如图」的题，PDF 里没有图。`hasFigure` 的题在题库检索时会被降权，但没有图形渲染。
3. **题干里的分式识别是保守的**：只认数字/单字母/括号组构成的分式；`a/b/c` 这种连分数、`3/4a` 这种歧义写法一律保持原文，宁少美化不改题意。
4. **知识图谱的节名是节号**（`2.1.1`），题库章节字段没有更细的知识点名称。
5. **dsh-tool-cards 的补丁只对 0.2.2 生效**，上游改版后自动跳过（不会装作成功）。
